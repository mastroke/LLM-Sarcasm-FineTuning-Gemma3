# Dataset Card

## Dataset

Toy sarcasm classification examples used for CI-safe baseline evaluation.

## Intended Use

- Demonstrate an evaluation pipeline.
- Provide a stable fixture for tests.
- Serve as a placeholder before adding a real benchmark dataset.

## Limitations

- Too small for real model conclusions.
- English-only.
- Not representative of cultural, regional or domain-specific sarcasm.

## Upgrade Path

- Add a public sarcasm benchmark with license notes.
- Split train, validation and test sets.
- Add data quality checks and label distribution reports.
