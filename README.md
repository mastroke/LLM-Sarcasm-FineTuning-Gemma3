# LLM Sarcasm Fine-Tuning (Gemma 3)

Legacy notebook-based fine-tuning experiments for sarcasm classification.

This work has been upgraded into a reproducible engineering project:

- [llm-finetuning-eval-lab](https://github.com/mastroke/llm-finetuning-eval-lab)

The upgraded repository adds:

- Dataset and model cards
- Deterministic evaluation baseline
- Reproducible metrics
- Tests and CI
- A clear path to LoRA/QLoRA fine-tuning
